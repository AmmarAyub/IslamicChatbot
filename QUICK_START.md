## What Can You Do?

### 💬 Chat
- Type Islamic questions
- Get instant replies from knowledge base

### ✍️ Flag Messages
- Click flag icon on any bot message
- Adds to scholar review queue

### 👥 Create Accounts
- Go to Settings
- Click "Manage Scholar Accounts"
- Create new scholar accounts

### 📋 Review Messages
- Click "Scholar Review"
- See all flagged messages
- Add comments
- Approve/reject

### ⚙️ Settings
- Change password
- Export database
- Clear all data
- Sign out

## Create New Scholar Account

1. Click "Create Scholar Account" on login screen
2. Fill form:
   - Username: (any name)
   - Password: (min 6 chars)
   - Confirm Password
   - Display Name: (optional)
   - Email: (optional)
3. Click Create
4. Sign in with your new account
